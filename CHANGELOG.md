# Changelog

All notable changes are documented in this file.

## 1.0.0 — 2026-09-05

### Added

- Product catalogue and supplier management APIs
- Durable inventory receipt and issue ledger
- Overselling and duplicate-reference protection
- API-key authentication with viewer, operator, and administrator roles
- Append-only authorization audit events
- Inventory metrics and CSV export
- Purchase-order and inventory-alert domain rules
- Liveness, readiness, CORS, request IDs, and security headers
- Non-root Docker and Compose packaging
- Automated lint, test, and container build checks
